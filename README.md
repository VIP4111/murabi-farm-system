# نظام إدارة الحلال — المرحلة 0 + 1 + 2

هذا الكود يغطي الأساس (أدوار وصلاحيات) + العمليات الأساسية (صيدلية، بيطرة، مالية):

- قاعدة بيانات حقيقية (SQLAlchemy، تشتغل بـ SQLite للتجربة المحلية، وتتحول لـ PostgreSQL بالإنتاج بتغيير سطر واحد بالإعدادات).
- نظام أدوار وصلاحيات **قابل للتوسيع بالكامل بدون كود** — الصلاحيات بيانات بقاعدة البيانات، والأدوار الثلاثة (مالك/دكتور/عامل) مجرد بداية افتراضية.
- نقطة دخول واحدة موحّدة لإنشاء أي حيوان (`app/core/animal_service.py`) — سواء بالشراء أو الولادة، بدل تعدد نقاط الدخول اللي كانت مشكلة النظام القديم.
- صفحة إعدادات حصراً لمن يملك صلاحية `settings.manage` (المالك) لتفعيل/تعطيل الخدمات الاختيارية، وكل خدمة معها "نشرة" توضح متطلباتها.
- سجل تدقيق (`AuditLog`) يسجّل أي إجراء حساس.
- واجهة واحدة (`home.html`) تعرض محتوى مختلف تلقائياً حسب صلاحيات المستخدم الحالي.
- **جديد بالمرحلة 2**: الصيدلية، الأطباء، الزيارات البيطرية، الأمراض، التطعيمات — وكلها تحسب **فترة السحب تلقائياً** من بيانات الدواء (`app/health/health_service.py`) بدل ما تُحسب يدوياً. سجل الحيوانات الآن يعرض "فترة سحب" لكل حيوان تلقائياً (مثال حي على تعاون الوحدات مع بعض).
- المالية: تسجيل بيع/شراء/مصروف، وإلغاء (لا حذف نهائي أبداً — يبقى بالسجل للتدقيق).

**نقطة ناقصة معروفة**: صلاحية `finance.health.view` (مالية الدكتور المحدودة بالصحة فقط) معرّفة بالصلاحيات لكن ما ربطناها بشاشة فعلية بعد — حالياً شاشة `/finance` تتطلب `finance.full.manage` (المالك فقط). نضيف شاشة مالية مصغّرة للدكتور بمرحلة لاحقة.

## التشغيل محلياً (للتجربة فقط)

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

cp .env.example .env
# عدّل .env حسب رغبتك (خصوصاً OWNER_PASSWORD)

export FLASK_APP=run.py
flask db init      # أول مرة فقط
flask db migrate -m "initial"
flask db upgrade
flask seed          # ينشئ الصلاحيات، الأدوار، حساب المالك، والخدمات

python run.py
```

افتح `http://127.0.0.1:5000` وسجّل دخول برقم الجوال وكلمة المرور اللي بملف `.env`.
